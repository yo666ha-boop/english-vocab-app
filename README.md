# みかみ塾 英単語アプリ

公開版:

**https://yo666ha-boop.github.io/english-vocab-app/**

## iPhoneで使う

1. Safariで公開版URLを開く
2. 上部から `教科書版` / `高校入試版` / `小学生版` を選ぶ
3. 教科書版では `教科書` → `学年` → 必要なら `大単元` → `小単元` を選ぶ
4. 必要に応じて `☆のみ` / `熟語だけ` / `現行確認のみ` / `暗記練習用にする` を使う
5. `問題数` を 5 / 10 / 15 / 20 / 30問から選ぶ
6. `出題形式` を `英語→日本語` / `日本語→英語` / `ランダム` から選ぶ
7. `テスト作成` を押す
8. 確認するときは `答え表示` を押す

印刷用には `問題を印刷`、`PDFで表示`、`解答を印刷`、`暗記プリントを印刷` が使えます。

ホーム画面から使う場合は、Safariの共有ボタンから `ホーム画面に追加` を選びます。
